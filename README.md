# Введение и контекст

## Общее описание проекта и цели

**Проект:** Внедрение системы онлайн-записи для сети барбершопов.

**Основная цель:** Развитие бизнеса через расширение клиентской базы, снижение трудозатрат сотрудников и автоматизацию процессов информирования клиентов.

## Структура проекта BSA (Barbershop)

Ниже представлено описание структуры папок проекта с указанием их содержимого и описания.

| Директория | Описание                                                                                                                                                                                                                                                                                                                                                  |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **BSA01**      | **1. Заинтересованные стороны** <br />Каталог стейкхолдеров, луковичная диаграмма, анализ ролей и их интересов. Определение всех, кто влияет на систему или подвергается её влиянию.                          |
| **BSA02**      | **2. Требования** <br />Сбор и документирование требований. Бизнес-требования, пользовательские требования, функциональные и нефункциональные требования.                                                                       |
| **BSA03**      | **3. Способы выявления требований** <br />Методы и техники сбора требований: интервью, анкетирование, наблюдение, анализ документов, мозговые штурмы, прототипирование.                                                 |
| **BSA04**      | **4. Предметная область и информационная модель** <br />Анализ предметной области, выделение сущностей, определение атрибутов и связей. Концептуальная модель данных, ER-диаграммы.                            |
| **BSA05**      | **5. Модели и диаграммы (DFD, State, Decision Table)** <br />Визуализация требований: диаграммы потоков данных (DFD), диаграммы состояний (State Diagram), таблицы решений (Decision Table).                                                                    |
| **BSA06**      | **6. Моделирование бизнес-процессов (BPMN)** <br />Описание бизнес-процессов в нотации BPMN. Выделение основных и обеспечивающих процессов, построение диаграмм процессов.                                                   |
| **BSA07**      | **7. Пользовательские истории (User Stories)** <br />Формирование пользовательских историй по ролям. Критерии приемки, тестовые сценарии, проверка по INVEST.                                                                                     |
| **BSA08**      | **8. Сценарии использования (Use Cases)** <br />Описание вариантов использования. Определение акторов, основного и альтернативных сценариев, связей include/extend.                                                                             |
| **BSA09**      | **9. База данных и словарь данных** <br />Логическая и физическая модели данных. Описание сущностей, атрибутов, типов данных, связей. Словарь данных (Data Dictionary).                                                                    |
| **BSA10**      | **10. Детализация требований** <br />Уточнение и детализация требований, выявленных на предыдущих этапах. Описание бизнес-правил, валидаций, алгоритмов.                                                                             |
| **BSA11**      | **11. Пользовательский интерфейс** <br />Макеты экранных форм (wireframes), описание навигации, интерактивных элементов. Определение операций и обеспечивающих функций (поиск, фильтрация, сортировка). |
| **BSA12**      | **12. Нефункциональные требования** <br />Атрибуты качества: производительность, доступность, надежность, масштабируемость, безопасность, долговечность, локализация.                                                  |
| **BSA13**      | **13. Проектирование функциональных требований** <br />Детальная спецификация функциональности. Описание бизнес-логики, алгоритмов, правил обработки данных.                                                                  |
| **BSA14**      | **14. Интеграции и REST API** <br />Описание взаимодействия с внешними системами: CRM, SMS-шлюз, мессенджеры, платежные системы. Спецификация интеграционных интерфейсов.                                                            |
| **BSA15**      | **15. REST API (форматы, маппинг, ошибки)** <br />Детальная спецификация REST API: форматы запросов и ответов (JSON/XML), маппинг данных, коды ошибок и их обработка.                                                                                    |
